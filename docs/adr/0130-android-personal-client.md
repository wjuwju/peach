# ADR-0130：安卓携带原版 Peach 与本机 CloudDrive2

- 状态：实验实现，待设备与账号验收
- 日期：2026-11-01

## 背景

安卓个人使用需要保留原版全部页面与业务实现，并在手机本机运行云盘核心、直接登录。Python 与媒体处理依赖以 ARM64 Linux 文件随包提供，由 PRoot 在应用私有目录执行；实际安卓启动与业务验收分别记录。

## 决策

`android/` 只负责原生窗口、前台服务、系统文件交互和额外的 CloudDrive2 管理页。主界面使用原版 WebView 页面，原版 Python 后端负责全部路由、ledger 和任务。前端不另写替代实现，随包保留原源码、迁移、资源与依赖锁。

核心由用户取得的官方归档作为本机构建输入。可执行文件位于 APK 原生库目录，由安卓安装器解压；网页资源在应用私有目录展开，核心由前台服务持有。停止只操作本服务持有的子进程，已有端口监听则报告冲突。

客户端只连接本机。密码只存在于请求期间，令牌由 Android Keystore 加密。管理 WebView 不提供 JavaScript 原生桥，不允许网页读取本地文件。

CloudDrive2 不要求安卓提供 FUSE。`android_cloud.py` 复用原版远程资源、扫描、媒体 HTTP 响应与 FFmpeg 回环桥；Windows 形态的账本路径与云盘逻辑路径单独映射。新增目录通过原版配置与凭据存储接入；改名、移动复用原版官方目录核验。安卓实例使用独立的数据根，不主动连接或修改已有桌面实例。

运行环境按 `runtime-inputs.json` 中的 Docker 官方 Python 镜像摘要、Debian 包摘要和 Termux 包摘要准备；主依赖与 amane 各用原锁，随包保留模型、许可证和 amane 对应源码。运行文件与用户数据分目录，升级沿用应用标识、签名和 CloudDrive2 配置目录。

安卓限制读取 `/proc/stat` 时，由 `CLOCK_BOOTTIME` 和实时时钟推算启动时间，固定为进程内的整数基准，保留 psutil 的进程身份比较语义。此适配仅在 `PEACH_ANDROID=1` 且原读取被权限拒绝时启用。

## 后果

核心许可、真实账号、后台限制和硬件解码分别验证。核心、官方网页和完整运行归档不进入公开仓库，不自动发布包含它们的 APK。包体积与首次展开时间增加；设备验证须覆盖原版后端、页面、云盘和媒体处理，不能用依赖导入或编译成功代替。桌面浏览器交互与硬件加速能力需按安卓环境单独确认。
