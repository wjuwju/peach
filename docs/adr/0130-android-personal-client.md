# ADR-0130：安卓个人客户端与桌面账本隔离

- 状态：实验实现，待设备与账号验收
- 日期：2026-11-01

## 背景

安卓个人使用需要在手机本机运行云盘核心并直接登录。桌面 Python 3.14 与媒体处理依赖不能未经安卓制品验证就视为可打包。

## 决策

`android/` 使用原生 Android SDK 和 gRPC Java，复用 CloudDrive2 官方公开协议和管理页。首版覆盖登录、目录、独立媒体库和播放，不声称完成 Python 刮削或完整桌面迁移。

核心由用户取得的官方归档作为本机构建输入。可执行文件位于 APK 原生库目录，由安卓安装器解压；网页资源在应用私有目录展开，核心由前台服务持有。停止只操作本服务持有的子进程，已有端口监听则报告冲突。

客户端只连接本机。密码只存在于请求期间，令牌由 Android Keystore 加密。管理 WebView 不提供 JavaScript 原生桥，不允许网页读取本地文件。

媒体库使用独立 SQLite，保存云盘逻辑路径，不写桌面 ledger。断点记录系统播放器报告的位置，不推断外部播放器进度。

## 后果

核心许可、真实账号、后台限制和硬件解码分别验证。核心与官方网页不进入公开仓库，不自动发布包含它们的 APK。刮削、NFO、字幕、封面和账本同步仍须移植，此子项目的构建不能作为其验收。
